# Naiia Health

**Community health context for primary care in Nova Scotia.**

Naiia Health is a web tool that lets a family physician type a patient's civic
address and instantly see the **social, economic and environmental context** of
the community that patient lives in — and then find **nearby health and community
services** to recommend during the same consultation.

It turns a residential address into a **Community Environ (CE)** — the geographic
unit used by the [Nova Scotia Health Atlas](https://experience.arcgis.com/experience/) —
and surfaces the relevant community indicators for that area, without using any
personal medical data.

> Formerly named *HealthLocate*. The GitHub repository is still `HealthLocate`.

---

## Why it exists

When a doctor recommends services (pharmacy, mental health, physiotherapy, labs…),
they rarely have tools that show **what resources exist near the patient** or the
**socioeconomic characteristics** of their neighbourhood. That gap leads to access
barriers, lower adherence and health inequities.

Naiia Health gives the physician a **contextual profile** that complements the
clinical picture — a 5-second read of whether the community conditions are
favourable or need attention, plus actionable, nearby services.

## Features

### Phase 1 — Community Profile
- **Address search with autocomplete** (Nova Scotia civic addresses).
- **A/B/C grades** per category vs. the provincial average (green / orange / red):
  - **Income & Economic** (MSI index)
  - **Social Vulnerability** (SCS index)
  - **Community Diversity** (SDS index)
  - **Transit / Active Living** (ALE index)
  - **Environment** (greenness, air & water — indicators shown; composite EQI pending)
- **Overall conclusion banner** — a one-line, plain-language summary.
- **Progress bars + detail cards**; clicking an indicator opens a card with its
  definition, the community's value and the NS average.
- **Small locator map** (Leaflet) zoomed to the patient's neighbourhood.
- **"Community at a glance"** — median age, no-family-doctor rate, median income, renters.

### Phase 2 — Social Prescribing
- Choose a service type (**Pharmacy, Mental Health, Physiotherapy, Walk-in Clinic,
  Laboratory**) and get the **top-5 nearest options** around the patient's address.
- Each result shows **name, address, distance, phone, hours, website** and a
  **"Get directions"** link (Google Maps).
- Data comes live from **OpenStreetMap** via the Overpass API.

### Print / Export
- A **customizable one-page PDF report**: the physician picks which service
  categories to include, and gets a clean sheet (community grades + recommended
  services) to **print, save to the patient file, or email**.

## Tech stack

| Layer     | Technology |
|-----------|------------|
| Backend   | Python · FastAPI · Uvicorn |
| Geospatial| GeoPandas · Shapely |
| Data      | Pandas |
| Frontend  | Vanilla HTML / CSS / JavaScript · Leaflet (map) |

No build step and no JS framework — the frontend is static files served by FastAPI.

## Data files

The `data/` folder is **git-ignored**, so datasets are **not** committed. To run
the project you need these files in place:

| File | Source | Notes |
|------|--------|-------|
| `shapefiles/ComEnviron.*` | NS Health Atlas — Community Environs boundaries | Committed to the repo |
| `data/NSHealthAtlasDataEnvirons.csv` | NS Health Atlas (Community Environs export) | Socio-economic + environment indicators |
| `data/ale_community_level.csv` | Active Living Environments (ALE), community-level | Transit / Active Living index (1–5) |
| `data/canale_by_ce.csv` | Generated by `scripts/build_canale_by_ce.py` | Legacy; superseded by `ale_community_level.csv` |

Addresses and nearby services are fetched **on demand** from public APIs, so no
address database needs to be downloaded.

## Setup

Requires **Python 3.10+** (developed on 3.14). GeoPandas pulls in GDAL/GEOS,
which install cleanly via `pip` on recent versions.

```bash
# 1. clone
git clone https://github.com/MarianaMera12/HealthLocate.git
cd HealthLocate

# 2. (recommended) create a virtual environment
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # macOS / Linux

# 3. install dependencies
pip install -r requirements.txt

# 4. place the data files (see "Data files") into data/
```

---

## Running

**Windows (PowerShell):**

```powershell
./run.ps1
```

**Any OS:**

```bash
python -m uvicorn backend:app --host 127.0.0.1 --port 8000 --reload
```

Then open **http://127.0.0.1:8000** in your browser.

> On Windows, set `PYTHONUTF8=1` before launching (already handled by `run.ps1`)
> so accented characters (µg/m³, ó, …) render correctly.

## API endpoints

The backend serves the frontend at `/` and exposes:

| Method & path | Purpose |
|---------------|---------|
| `GET /api/suggest?q=` | Address autocomplete (NS Open Data SODA API) |
| `GET /api/profile?lat=&lng=&address=&community=` | Community Environ + all category grades & indicators |
| `GET /api/ns-outline` | Nova Scotia silhouette (GeoJSON) for the locator map |
| `GET /api/services?lat=&lng=&category=` | Top-5 nearby services (OpenStreetMap Overpass) |

Interactive docs are available at **http://127.0.0.1:8000/docs**.

## Data sources & attribution

- **NS Health Atlas** — Community Environs and community indicators.
- **Nova Scotia Open Data** — [Civic Addresses](https://data.novascotia.ca/) (SODA API).
- **Active Living Environments (ALE)** — community-level walkability / transit index.
- **OpenStreetMap** contributors — nearby services via the Overpass API
  (data © OpenStreetMap, ODbL). Map tiles © OpenStreetMap © CARTO.

Naiia Health uses **only public, aggregated, community-level data**. It stores no
personal medical information and makes no diagnoses — it provides **geographic and
social context** to support more informed, equitable care.
